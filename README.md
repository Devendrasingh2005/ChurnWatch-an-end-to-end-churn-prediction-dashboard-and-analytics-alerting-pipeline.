# ChurnWatch-an-end-to-end-churn-prediction-dashboard-and-analytics-alerting-pipeline.
Built ChurnWatch: a churn prediction dashboard (AUC 0.81) that ranks subscribers by cancellation risk, plus a Python pipeline that loads web analytics into a warehouse and alerts on traffic anomalies. Stack: Python, scikit-learn, pandas, BigQuery, Chart.js. Trained on synthetic data.
